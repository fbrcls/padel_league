Préparer les secrets Cloudflare

Cet outil fonctionne sur votre ordinateur. Il ne transmet aucune donnée et ne fait aucune connexion réseau. Aucun secret n’est enregistré automatiquement.

Au moins 16 caractères. Conservez-le dans votre gestionnaire de mots de passe : il servira à vous connecter à l’application.

À enregistrer comme secrets dans Cloudflare

Empreinte du mot de passe. Ne mettez pas le mot de passe en clair dans ce champ Cloudflare. Clé de chiffrement des liens personnels. Gardez-en une copie privée ; ne la remplacez pas une fois les liens distribués.

Dans Cloudflare : ouvrez votre Worker → Settings → Variables and Secrets → Add. Pour chaque valeur, choisissez le type Secret et le nom exact indiqué ci-dessus. Ne partagez pas ces valeurs dans une conversation.
